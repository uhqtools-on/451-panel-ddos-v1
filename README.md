# TUTO PANEL DDOS
D'abord, si vous n'avez pas python, installez le dans :
 https://python.org/download/

Executez le fichier *start.bat* pour installer les modules requis et executer le fichier *main.py*

Une fois le panel lancé, renseignez :
- ip / domaine
- vecteur d'attaque
- nombre de bots
- payloads
- durée
- port
- chemin
